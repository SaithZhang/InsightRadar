# ADR-0019：Research Library 管理证据，业务模块拥有判断

日期：2026-11-08。状态：职责与架构约束已由用户确定；实现未准入。

## 背景

既有需求 `IR-BL-RLIB-001`、`IR-BL-ZSXQ-001` 需要明确资料能力与研究/策略的边界。仓库已有下载、PDF、研究卡、JSON/JSONL 和 SQLite 能力，缺少统一资料合同；下载成功不代表统一资料库完成。

## 决定

- 在现有 InsightRadar 模块化单体中规划 Research Library，职责为 Connector、采集/解析、原件/版本管理、检索与证据引用；无 BUY/SELL、仓位、Permission 或交易逻辑。
- 统一资料模型与只读合同不依赖具体平台响应、研究卡或账户。先复用原件、解析及现有存储技术，不新建应用、仓库、服务、向量库或队列。
- 原始资料、第三方主张、AI 派生结果分别记录；引用固定版本与原文定位，转载去重保留来源关系及限制，未知不补造。会员读取不授权再分发或外部模型处理。
- 首个来源为知识星球「前沿信息收录」，继承已验证工具与明确缺口；Meet Kevin 05C/05D、Thesis Book 等保留原流程，只在后续已准入切片中按需接入。
- 规划归 Core 的研究证据职责；当前拓扑仅增加无运行连线的规划节点，既有 ZSXQ 工具仍为 Extension。四路由、V3.1 顺序准入、V0.01 冻结范围及 feat-060 状态保持。

## 后果与停止线

本次交付只包括需求、模型与验证计划。未来能独立抽离是待验收目标，不是现在已提供 API/MCP 的声明；实际抽离仍按产品章程的必要性门槛。唯一后续为用户准入一份指定资料到既有消费者的最小切片；未准入前停止。

细化合同、已有代码依据、验证台账及目标验收见 [Research Library](../../research-library.md)。
