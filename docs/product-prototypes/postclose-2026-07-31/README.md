# 2026-07-31 盘后／周末复盘静态原型

这是一个与正式应用完全隔离的本地静态原型，用于验证一个问题：用户能否在 10 秒内看懂 2026-07-31 收盘发生了什么、账户受到什么影响、下一个交易日等待确认什么。

## 打开方式

双击 `index.html`，或在浏览器中打开该文件。页面不请求网络、不连接运行时、不写入计划或交易账本。

## 数据边界

- 页面使用本地真实账户汇总与持仓快照，属于私有数据。
- 原型和截图不得提交、发布或用于公开演示。
- 588200.SH 的技术均线、支撑和阻力数据因复权或标的映射口径异常而停用，页面不复制任何错误技术位。
- 页面只继承现有计划草案；当前版本均未获用户接受，因此全部保持“待确认”，不产生实时交易动作。

## 原型范围

仅包含盘后／周末复盘单页。没有正式路由、后台调用、数据源修复、实时刷新、盘前或盘中页面。
