# 外部专家待回答问题

本轮评审不得重新设计四页结构。请优先回答以下问题。

## 安全与状态

1. 是否存在 blocked 计划通过其他入口被误标为有效计划的边缘场景？
2. `plan_id + plan_version` 范围是否足以避免旧回应污染新规则？
3. 数据 stale/missing/blocked 的失败关闭是否还有明显漏口？
4. 本地 JSONL 原子追加和 loopback Token 在单用户 Pilot 下有哪些 P0 级风险？

## 十次真实试用

1. 每次晨间最少应记录哪些事实，才能判断产品是否减少遗忘和错配？
2. 哪些问题应立即中止试用，哪些只应进入普通体验清单？
3. 10 次样本结束后，启动 V3.1 的最低证据门槛是什么？

## 投资工作流

1. 条件规则是否足够区分市场许可、持仓动作和失效条件？
2. 哪些数据错误最可能造成真实决策伤害？
3. 在不增加页面和实时预警的前提下，现有晨间闭环是否可被真实执行？

## 请不要输出

- 新的信息架构；
- P1/P2 实施计划；
- 自动交易设计；
- 用 AI 替代规则或人工确认；
- 仅凭固定截图推导投资建议。
