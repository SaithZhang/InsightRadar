# AI 与 Agent 架构

## P0 权威顺序

1. 数据健康与市场许可；
2. 结构化规则；
3. 用户明确回应；
4. AI 解释。

AI 位于最后一层，不能推翻前三层。

## 当前实际情况

- P0 计划由 Python 规则生成；
- after-close workspace 明确记录 `AI未使用`；
- 没有用户 AI 对话页；
- 没有自动交易 Agent；
- 研发 Agent Harness 用于工程治理，不是面向用户的投资 Agent。

## 未来但未启动的 P1 约束

- 只处理公告、研报、新闻等非结构化解释；
- 证据未变化时必须命中本地缓存；
- 输出要带来源、时间、模型/Prompt 版本和失败状态；
- AI 只能总结和解释，不得把 blocked 改成 accepted；
- 不得补造价格、技术指标、持仓字段或回测结果。

## 安全边界

- 无下单权；
- 无强制覆盖阻断；
- 客户端提交的计划状态不可信，服务端按当前版本再校验；
- 响应记录按计划版本隔离；
- 真实密钥、账户和持仓不进入专家分享包。
