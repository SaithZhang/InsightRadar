# 已知问题与技术限制

| 编号 | 当前限制 | 影响 | 冻结期处理 |
| --- | --- | --- | --- |
| IR-01 | 标的研究尚无真实 P1 编排 | 不能把页面当完整个股研究终端 | 不开发；仅记录体验 |
| IR-02 | 无五分钟盘中监控 | 已确认计划不会收到实时提醒 | P2 不启动 |
| IR-03 | 无回测历史中心 | 不能据此证明策略收益 | P1 不启动；后验不足保持 pending |
| IR-04 | 晨间复核不是实时行情刷新 | 08:30 可能仍需人工识别最新市场变化 | 页面已明确边界；错误标记才修复 |
| IR-05 | 真实持仓可能有 unknown 字段 | 风险和计划会被阻断 | 保持失败关闭，不自动推断 |
| IR-06 | 数据源可用性受网络/供应商影响 | 来源可 stale/missing/blocked | 只修复错误分类或核心阻断 |
| IR-07 | JSON/JSONL 适合本地单用户 | 不支持多用户事务和权限 | V3.0 不扩展 |
| IR-08 | 无用户 AI 对话/投资 Agent | 不能自由问答或代理执行 | 不属于 P0 |
| IR-09 | 无自动交易 | 必须人工执行计划 | 刻意安全边界，不修复 |
| IR-10 | 后验样本不足 | 无法证明长期价值 | 完成 10 次晨间试用后集中复盘 |
| IR-11 | 当前 P0 工作区未整理成干净独立提交 | 外部代码审计需结合工作区 | 包内明确 Git + workspace 快照 |
| IR-12 | 缺少正式前端 E2E/视觉基线套件 | UI 变更主要依赖单测和浏览器验收 | Scope Frozen 降低变化面；安全缺陷优先 |

## 冻结期允许修复

- 数据错误；
- 计划错配；
- 状态持久化失败；
- 安全问题；
- 核心流程阻断。

## 冻结期不立即开发

- 普通视觉、密度、文案或操作偏好；
- 新指标、新入口、新页面；
- P1/P2；
- 云、多用户、移动端；
- 自动交易或强制覆盖阻断。
