# 产品概述

## 一句话定位

InsightRadar 是本地、单用户、规则优先的 A 股决策情报工作台：把分散证据整理成可审核的条件计划，帮助用户在开盘前记住、复核和确认当天应做与不应做的事。

## 北极星

`Observe -> Explain -> Decide -> Verify`

产品不以页面或指标数量证明价值，而以是否减少遗忘、错配、冲动操作和无法复盘的决策为准。

## 当前阶段

**InsightRadar V3.0 Pilot — Scope Frozen**

P0 已通过验收，进入连续 10 次真实晨间决策试用。当前不是商业化、多用户或自动交易产品。

## 已冻结的产品合同

| 合同 | 当前定义 |
| --- | --- |
| 核心用户 | 产品负责人本人，本地单用户 |
| 核心时刻 | 盘后生成，次日约 08:30 复核 |
| 核心输入 | 已批准持仓、市场约束、研究/公告变化、数据健康 |
| 核心输出 | 可解释的 IF/THEN/UNTIL/INVALID 条件计划 |
| 人工责任 | 接受、异议、稍后、作废或确认知悉阻断 |
| 系统责任 | 保存版本、状态、证据和用户回应；缺口失败关闭 |
| 禁止事项 | 自动交易、用 AI 补造缺失数据、把诊断指标当交易授权 |

## 四页结构

1. 今日计划：只展示当前需要人工处理的 `pending` 计划；
2. 组合风险：展示真实持仓映射、风险和数据缺口；
3. 标的研究：保存研究任务边界；P1 编排尚未启动；
4. 复盘账本：展示计划版本、回应和已有后验成熟度。

市场约束、主题温度和数据状态是证据或诊断层，不再扩展为新的一级页面。

## 当前不做

- P1 研究编排与回测历史中心；
- P2 五分钟盘中预警和通知；
- 云部署、多用户、移动客户端；
- AI 策略权威或自动下单；
- 试用期普通体验建议的即时开发。
