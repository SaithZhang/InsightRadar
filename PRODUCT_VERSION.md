# InsightRadar Product Version

**InsightRadar V3.0 Pilot — Scope Frozen**

- Status effective: 2026-07-25
- P0 acceptance: passed
- Active phase: 10 consecutive real morning decision trials
- Frozen: four-page information architecture, core decision loop, responsibility boundaries
- Deferred: P1 research orchestration, backtest history center, P2 five-minute intraday alerts

During the trial, changes are limited to data errors, plan mismatches, state-persistence failures, security issues, and core-flow blockers. Ordinary experience feedback is recorded for the post-trial review and is not implemented immediately.
